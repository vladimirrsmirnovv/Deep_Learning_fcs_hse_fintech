# activations


Работу нужно делать в ноутбуке `hw_activations.ipynb`

Можно посмотреть в тесты в репозитории [checkhw](https://github.com/fintech-dl-hse/checkhw/tree/main/tests/activations)

Как запускаются тесты и сколько баллов можно получить за каждый тест можно посмотреть [тут](https://github.com/fintech-dl-hse/checkhw/blob/main/.github/classroom/autograding-activations.json). Баллы в пайплайнах нельзя сделать дробным числом. Максимум за домашку можно получить 100 баллов в пайплайнах. Что соответствует 1 баллу в итоговой формуле.

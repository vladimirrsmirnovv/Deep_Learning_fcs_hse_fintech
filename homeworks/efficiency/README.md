
# Efficiency

## Запуск в колабе

Для запуска в колабе, надо подкостылить зависимости **и перезапустить рантайм**
```
pip install -U datasets fsspec==2023.9.2
```

## Цель:
В этой домашке нужно затюнить с помощью LoRA модель GPT-2.

## Ограничения:
* Время - время исполнеия скрипта должно нужно уложиться в 240 секунд (4 минуты)
* Скользящее среднее значение loss должно быть меньше 2.0

## Что можно изменять:
* Любое тело ф-ии в файле `efficiency.py` (но не интерфейс, т.е. нельзя менять входные и выходные аргументы ф-ий)

## Обратите внимание:
* В колабе T4 GPU не поддерживает `torch.compile`, поэтому ускорение вы можете не заметить в колабе. Но в автогрейдере используется L4 (T4i) - на этой GPU эффект `torch.compile` будет более заметен. Ускорение может быть в несколько раз. Мое решение в колабе отрабатывает за 30 минут. В то время как в автогрейдере отрабатывает меньше чем за 4 минуты.
* Не нужно тюнить все параметры модели, используйте LoRA в `prepare_model`
* Обратите внимание на варнинги в автогрейдере
* Количество данных для обучения изменять нельзя. Нужно сделать полный цикл итераций по входным данным

## Что должно сработать:
* LoRA адаптер
* `torch.compile`
* `bfloat16` (он, к сожалению, тоже не поддерживается в коллабе)
* Optimal Batch Size

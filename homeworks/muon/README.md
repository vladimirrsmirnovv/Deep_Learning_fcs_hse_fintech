# Homework: Muon and Newton–Schulz

This repository is the homework **hw-muon** on the Muon optimizer and Newton–Schulz orthogonalization.

## Tasks

1. **Newton–Schulz orthogonalization (100 points)**
   Implement `schulz_orthogonalize(X, num_steps, kappa)` in the notebook.

2. **Muon optimizer (100 points)**
   Implement the `Muon` optimizer class (subclass of `torch.optim.Optimizer`) in the notebook.

3. **Optional: comparison with Adam and singular values**
   Train an MLP with Muon and Adam and compare singular values of update matrices (not graded).

# Задача

В этой домашке вам предстоит реализовать собственную версию BPE Tokenizer.
Но для простоты мы **НЕ БУДЕМ** спускаться на уровень байт - будем работать с символами.

Часть кода и интерфейс класса уже описаны. Менять их не рекомендуется.
Потому что тесты полагаются на этот интерфейс. Изменять тесты не рекомендуется. И даже если вы измените их в репозитории, в автогерйдере тесты запускаются из другого репозитория, чтобы не было возможности подкрутить тесты.

# Ограничения

* Не спускаемся на уровень байтов. Работаем с символами.
* Не делаем претокенизацию. Пробелы могут быть частью токена в словаре. Даже несколько слов подряд могут быть одним токеном в словаре. Обратите внимание на `test_fitted_tokenizer_vocab`
* У тестов в автогрейдере есть ограничение по в ремени. Тесты должны исполниться за 20 секунд. Это с запасом даже для не очень оптимальной реализации. Если вы вышли за лимит этого ограничения, скорее всего, у вас очень-очень неоптимальное решение.


# Ресурсы:

* Описание алгоритма BPE Лены Войты - [ссылка](https://lena-voita.github.io/nlp_course/seq2seq_and_attention.html#bpe)
* Описание алгоритма BPE HuggingFace Tokenizers - [ссылка](https://huggingface.co/learn/nlp-course/chapter6/5). Вы можете пользоваться частями кода, но обратите внимание, что пример кода из этой статьи не соответствует некотрым ограничениям

# Тесты

Запуск тестов:
```bash
pytest tokenizer_test.py
```

В идеале, вам следуюет подумать про оптимальность решения. Тесты должны проходить быстрее, чем за 4 секунды.

# Пожелания к процессу выполнения домашки

Эта домашка не требует GPU. Вы можете запустить тесты локально - на ноутбуке.

В рамках этого ДЗ попробуйте воспользоваться `AI Agents`-инструментами
для написания кода. Рекомендую попробовать [`Cursor`](https://www.cursor.com/). У него есть двухнедельный триал, но и даже бесплатная версия неплохо работает. Есть еще [Trae](https://www.trae.ai/), [cline](https://github.com/cline/cline), [Tabbyml](https://www.tabbyml.com/) и другие.

Рекомендую ознакомиться с обзором тулзов для AI Agents [на хабре](https://habr.com/ru/articles/889310/), в основном первую часть статьи. Во второй части рассказывается про self-hosted запуск LLM, но я бы не рекомендовал с этого начинать, если до этого вы не пробовали другие инструменты.
